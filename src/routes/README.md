# MAET Frontend Route Architecture

MAET uses **TanStack Start file-based routing**. Every route file in this directory maps directly to a path or layout in the application.

> **Note:** `src/routeTree.gen.ts` is auto-generated by `@tanstack/router-plugin`. Never edit it manually.

---

## Route Hierarchy

```
__root.tsx                                # App root shell: HTML, meta, theme script, <Outlet />
├── index.tsx                             # Landing page (/)
├── _app.tsx                              # Authenticated workspace layout (Navbar, Ticker, Sidebar)
│   ├── _app.dashboard.tsx                # Market overview dashboard (/dashboard)
│   ├── _app.terminal.tsx                 # Execution & research terminal (/terminal)
│   ├── _app.chart.$symbol.tsx            # Candlestick chart & indicators (/chart/:symbol)
│   ├── _app.chart-grid.tsx               # Multi-symbol monitoring grid (/chart-grid)
│   ├── _app.stock.$symbol.tsx            # Company profile & metrics (/stock/:symbol)
│   ├── _app.compare.tsx                  # Peer comparison analysis (/compare)
│   ├── _app.heatmap.tsx                  # All-NSE heatmap & breadth; NIFTY 50 from public quotes when signed out (/heatmap)
│   ├── _app.universe.tsx                 # NSE stock universe browser (/universe)
│   ├── _app.screener.tsx                 # Stock screener with saved presets (/screener)
│   ├── _app.watchlists.tsx               # User watchlists (/watchlists)
│   ├── _app.alerts.tsx                   # Server-side alert monitoring (/alerts)
│   ├── _app.orders.tsx                   # Paper trading orders & blotter (/orders)
│   ├── _app.portfolio.tsx                # Paper trading positions & balances (/portfolio)
│   ├── _app.performance.tsx              # Paper trading performance analytics (/performance)
│   ├── _app.journal.tsx                  # Research journal & trade theses (/journal)
│   ├── _app.options.$underlying.tsx      # NSE options chain (/options/:underlying)
│   ├── _app.futures.tsx                  # Futures placeholder: no futures feed is connected (/futures)
│   ├── _app.strategies.index.tsx         # Strategy catalog (/strategies)
│   ├── _app.strategies.$strategyId.index.tsx  # Strategy editor (/strategies/:strategyId)
│   ├── _app.strategies.$strategyId.backtests.tsx   # Backtest runs (/strategies/:strategyId/backtests)
│   ├── _app.strategies.$strategyId.deployments.tsx # Strategy deployments (/strategies/:strategyId/deployments)
│   ├── _app.backtest.tsx                 # Standalone backtesting engine (/backtest)
│   ├── _app.replay.tsx                   # Historical market replay simulator (/replay)
│   ├── _app.news.tsx                     # Sample headlines (no market news feed connected) (/news)
│   ├── _app.settings.tsx                 # Theme, shortcuts, browser data (/settings)
│   ├── _app.workspace.tsx                # Workspace manager (/workspace)
│   └── _app.admin.data-quality.tsx       # Public data status (backend health, quote source) + admin ingestion audits (/admin/data-quality)
```

## Server Route Handlers (REST)

| Route File | HTTP Method | Endpoint | Description |
|---|---|---|---|
| `api.market.quotes.ts` | GET | `/api/market/quotes` | Batch equity & index quotes with freshness headers |
| `api.market.candles.ts` | GET | `/api/market/candles` | Historical OHLCV candle series |
| `api.market.corporate-actions.ts` | GET | `/api/market/corporate-actions` | Dividends and splits from Yahoo Finance, newest first (24 h server cache) |
| `api.market.companies.ts` | GET | `/api/market/companies` | Listed equities master directory |
| `api.market.company.ts` | GET | `/api/market/company` | Single company fundamentals & profiles |

## Route Integrity Tests

Automated regression and static integrity tests reside in this folder prefixed with `-*`:

- `-alerts-integrity.test.ts`: Validates alert routing, contract isolation, and trigger history.
- `-compare-integrity.test.ts`: Verifies peer comparison routing contracts.
- `-journal-integrity.test.ts`: Ensures honest metrics and no fabricated trade statistics.
- `-market-intelligence-integrity.test.ts`: Verifies breadth gauge and heatmap provider provenance.
- `-news-integrity.test.ts`: Enforces explicit UI demo / fixture notices for unintegrated news.
- `-options-chain-integrity.test.ts`: Guards options chain availability disclosures.
- `-root-csp.test.ts`: Tests Content Security Policy headers on root document.
- `-saved-screener-persistence.test.ts`: Asserts database-backed screener preset flows.
- `-watchlists-integrity.test.ts`: Verifies watchlist persistence and migration consistency.
