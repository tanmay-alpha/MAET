# MAET Final Runtime Defect Audit

This document records all pre-fix runtime defects, missing property mappings, risk gate gaps, and evaluation defects reproduced prior to applying engineering fixes.

| Defect ID | Route / Module | Steps to Reproduce | Visible Symptom | Console Error / Root Cause | Backend Log / Suspected File | Severity | Fix Summary |
|-----------|----------------|-------------------|-----------------|----------------------------|------------------------------|----------|-------------|
| DEF-001 | Strategy Evaluator | Run `evaluatorWorkerLoop()` on active deployment | Strategy evaluator silently accessed undefined fields | `user_id`, `strategy_version_id`, `kill_switch_enabled` property mismatches | `server/workers/strategy-evaluator.ts` | P0 | Aligned all properties to Drizzle camelCase (`userId`, `strategyVersionId`, `userKillSwitch`, `deploymentKillSwitch`, `riskLimits`) |
| DEF-002 | Deployment Risk Gate | Trigger signal in `AUTO_PAPER` mode | Risk gate evaluated with dummy inputs (`50000`, `1`, `1000`) | Hardcoded cash and position inputs instead of loading real paper account state | `server/workers/strategy-evaluator.ts` | P0 | Replaced hardcoded inputs with canonical queries against PostgreSQL `paperAccounts` and `paperPositions` |
| DEF-003 | Manual Proposal Execution | Call `confirmProposal` tRPC mutation | Default fallbacks triggered (`RELIANCE`, `BUY`, `qty: 1`) | Missing proposal validation and missing risk gate re-check | `server/api/trpc/routers/strategy-deployments.ts` | P0 | Enforced signal validation, proposal expiration check, risk gate re-evaluation, and exact proposal quantity/side execution |
| DEF-004 | Bar Replay Engine | Execute `strategyReplay.step` procedure | `Cannot find name 'sql'` & invalid raw SQL with unbound `$1, $2, $3` parameters | Missing `sql` import and raw string query | `server/api/trpc/routers/strategy-replay.ts` | P1 | Fixed Drizzle query syntax, imported `sql`, and isolated replay orders/fills/positions/ledger inside replay session state |
| DEF-005 | Portfolio Backtest Coordinator | Run `runPortfolioBacktest` with multi-symbol input | `Date.now()` used for initial equity timestamp, sector exposure ignored | `Date.now() - 90 * 86400000` timestamp calculation and missing sector limit enforcement | `server/domain/strategy/portfolio-runner.ts` | P1 | Derived initial equity timestamp strictly from earliest input candle and enforced sector exposure limits |
| DEF-006 | Parameter Sweep Worker | Run sweep across strategy AST | Fuzzy parameter string matching in AST rules | `obj.indicator.type?.toLowerCase()?.includes(k.toLowerCase())` | `server/workers/sweep-worker.ts` | P1 | Replaced fuzzy matching with explicit typed parameter path injection and safe numeric formatting |
